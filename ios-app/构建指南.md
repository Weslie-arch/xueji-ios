# 学迹 iOS App（液态玻璃）构建与安装指南

> App 本体在 `ios-app/`，云构建流程在 `.github/workflows/build-ipa.yml`。
> 液态玻璃用的是 **iOS 26 官方 Liquid Glass**：系统 `TabView` 底栏在 iOS 26 上自动呈现官方液态玻璃效果，卡片使用官方 `glassEffect` API；iOS 17–25 自动回退毛玻璃，不影响使用。

## 一、云端打包 IPA（Windows 上就能做，不需要 Mac）

1. 把整个项目（含 `ios-app/` 和 `.github/`）上传到一个 GitHub 仓库
2. 打开仓库 → **Actions** → 左侧选 **Build iOS IPA (unsigned)**
3. 点 **Run workflow** 手动触发（push 了 ios-app 目录也会自动触发）
4. 构建完成后在该次运行页面底部 **Artifacts** 下载 `XueJi-unsigned-ipa`
   —— 得到的是 **未签名 IPA**（免费 Apple ID 无法在云端签名，属正常流程）

> 提示：构建机需要 Xcode 26 SDK 才能编译 `glassEffect`。GitHub 的 `macos-latest` 在 2026 年已自带；若报 `glassEffect` 找不到，把 workflow 里 `macos-latest` 改成 `macos-26`。

## 二、签名安装到 iPhone（免费 Apple ID 即可）

1. Windows 电脑安装 **Sideloadly**（sideloadly.io）或 **AltServer**（altstore.io）
2. iPhone 用数据线连接电脑，首次连接手机上点「信任」
3. 打开 Sideloadly：
   - Apple ID：填你的免费 Apple ID
   - IPA file：选刚下载的 `XueJi-unsigned.ipa`
   - 点 **Start** —— 自动重签并安装到手机
4. 手机上：设置 → 通用 → VPN 与设备管理 → 信任你的 Apple ID 证书
5. 完成。**免费 Apple ID 签名 7 天有效**，过期后手机打开 AltStore/Sideloadly 重签一次即可（数据都在云端，不影响）

## 三、App 功能

- **登录**：填服务器地址（默认 https://xueji.misktool.top）+ 学迹账号密码，会话与网页端通用（Cookie 自动登录）
- **概览**：考试次数、总体得分率、各科平均得分率、最近考试
- **成绩**：全部考试记录，按日期分组
- **AI 助手**：走服务端统一转发（密钥不经过 App），回答会结合你的学习数据
- **我的**：账号、AI 余额、服务器地址、退出登录
- 数据全部通过 API 实时读取，**与网页端完全同步**（同一账号、同一份云端数据）

## 四、本地开发（可选，有 Mac 时）

```bash
cd ios-app
brew install xcodegen
xcodegen generate          # 生成 XueJi.xcodeproj
open XueJi.xcodeproj       # Xcode 里直接 Run
```

## 五、文件结构

```
ios-app/
  project.yml              # xcodegen 项目定义（不用手写 .xcodeproj）
  XueJi/
    Models.swift           # 数据模型（与网页端 state 结构对应）
    APIClient.swift        # 网络层：PHP/Node 自适应探测 + Cookie 会话 + AI SSE 解析
    Views.swift            # 登录页 / 液态玻璃 Tab / 概览 / 成绩 / AI / 我的
.github/workflows/
  build-ipa.yml            # GitHub Actions 云构建（产出未签名 IPA）
```
